## 踩过的坑（复用价值高）
1. **GitHub 连不上**：有代理 `127.0.0.1:10383`，curl 报 `CRYPT_E_NO_REVOCATION_CHECK`。
   解法：`curl --ssl-no-revoke` / git `http.sslVerify false`
2. **pip 装成 CPU 版 torch**：`--extra-index-url` 让 pip 从 PyPI 挑了 CPU wheel。
   解法：锁版本 `torch==2.11.0+cu128` 且不给备胎源。CUDA wheel 2.5GB vs CPU 124MB 可肉眼判断
3. **Ollama 模型不存在返回 404 + JSON body**，`raise_for_status()` 会吞掉 body。
   解法：4xx/5xx 必须先 `await resp.aread()` 读 body 再抛
4. **本机代理会拦本地端口**：测本地服务 curl 加 `--noproxy '*'`，httpx 用 `trust_env=False`
5. 后台进程随工具调用结束被回收，常驻服务要用 `run_in_background: true`
