# web/src/api — 唯一的后端耦合点

| 文件 | 干什么 | 为什么不这么干不行 |
|---|---|---|
| `stream.ts` | 订阅后端 SSE 事件流，转成 `types/events.ts` 里的类型 | 订阅逻辑散在各组件里，每个组件都要自己处理解析和异常，必然不一致、必然漏 |
| `audiobook.ts` | 有声书的 REST 调用 + 解析/合成进度流订阅 | 有声书多了进度流和音频 URL 约定，需要统一的订阅生命周期管理（EventSource 开关） |

## 约定

- 音频走**相对路径** `/audio/{novelId}/...`（由 Vite 代理转发到后端），
  不依赖数据库里存的绝对路径 —— 否则换机器部署音频全 404。
- 这一层是**唯一允许知道后端存在**的地方。后端改接口，只改这里。
