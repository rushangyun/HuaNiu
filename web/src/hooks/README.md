# web/src/hooks — 订阅逻辑（组件不含网络代码）

| 文件 | 干什么 |
|---|---|
| `useChat.ts` | 对话状态：订阅 token / 工具调用 / 轮次事件 |
| `useVisionStats.ts` | 视觉统计：检测帧、类别计数 |
| `useAudiobook.ts` | 有声书：列表 / 详情 / 段落 / 进度流 |

## 踩过的坑（值得记住）

打开一本书时**只在打开瞬间拉一次详情和段落**，而 SSE 只推进度、不回刷内容 ——
结果**后端早已解析完成，界面却一直卡在"解析中"**，用户以为功能坏了。

修法：SSE 阶段切到 `parsed / done / error` 时，**回刷详情与段落**。
核心教训：**进度流和内容流是两回事，推了进度不等于内容也更新了**。
