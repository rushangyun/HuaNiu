# app/transport — 推送层（只负责发，不含业务）

| 文件 | 干什么 | 为什么不这么干不行 |
|---|---|---|
| `sse.py` | 把事件编成 SSE 帧推给前端 | 编码逻辑混在业务代码里，将来换 WebSocket 就得全量重写 |

## 两个踩过的坑

1. **终止帧必须用标准 `[DONE]`**。
   原来用 `data: done`，和业务事件 `DoneEvent(type="done")` **撞名** ——
   前端分不清收到的到底是"流结束"还是"一个 done 业务事件"。

2. **SSE 不能缓冲**。
   经过代理/中间件时如果被缓冲，流式打字机效果会变成一次性吐出。
   必须在响应头和中间件层面**显式禁用缓冲**，否则本地没问题、部署后出问题。
