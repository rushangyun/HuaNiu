# app/agent/tools — 工具（按用途拆文件）

| 文件 | 工具 | 为什么不这么干不行 |
|---|---|---|
| `base.py` | 工具注册 + **从函数签名和 docstring 自动推断 JSON Schema** | 手写 Schema 一定会和函数实现漂移；自动推断后新增工具只写一个函数 + 类型标注 + docstring |
| `system.py` | 当前时间 / 计算器 / 设备信息 | 计算器用 **AST 白名单求值**。`eval` 等于把 Python 执行权交给模型输出，是典型 RCE 漏洞 |
| `filesystem.py` | 列目录 / 读文件 | 有沙箱（`_safe_path` 拒绝 `..` 逃逸和绝对路径）。让模型能读文件是能力，不让它读到系统文件是底线 |
| `vision.py` | 检测图片 / 摄像头画面里的物体 | 走工具注册表，而不是让 agent 直接 import `vision` —— 否则同层互相依赖，架构就成网了 |

## 铁律：工具永不抛异常

`ToolRegistry` 执行时捕获所有异常，转成**人类可读的字符串**返回。

- 异常冒到主循环 → 直接中断 Agent；
- 转成字符串 → **模型能读到错误并自己改正**（比如路径写错了会自己重试换个路径）。

这不是"为了不崩"，而是**把错误变成模型可以推理的信息**。
