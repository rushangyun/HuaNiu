# app/api — HTTP 路由（薄）

| 文件 | 干什么 |
|---|---|
| `chat.py` | 对话流（SSE 流式返回 token / 工具调用 / 轮次） |
| `vision.py` | 视觉检测、MJPEG 推流 |
| `health.py` | 健康检查 `/api/health`（探测本地模型是否可达、视觉是否就绪） |
| `audiobook.py` | 有声书：建书 / 解析 / 合成 / 进度流 / 下载 |
| `deps.py` | 从容器取依赖的公共帮助函数 |

## 这一层必须保持"薄"

只做三件事：**入参校验 → 调下层 → 返回结果**。一行业务逻辑都不写。

- 业务逻辑写在 api 里 → 换框架（FastAPI → 别的）就得整个重写；
- 业务逻辑写在下层 → api 只是换个壳，业务一行不动。

## 关于异步任务

像有声书的解析/合成这种耗时操作，路由里用 `asyncio.create_task` 丢到后台，**立刻返回 id**，
前端再靠 SSE 进度流看进展。不要让 HTTP 请求一直挂着等几分钟。
